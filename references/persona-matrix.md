# 人格判定矩阵(persona-matrix)

> 本文档定义 mcd-vibe-commit 的答题维度、计分规则与人格判定矩阵。
> 代码实现见 `scripts/persona.py`, 两边必须保持一致。

## 一、测评维度

| 维度 | 含义 | 分值范围 |
|---|---|---|
| `late_night` | 凌晨浓度(熬夜/夜生活倾向) | 0-3 |
| `spicy` | 嗜辣程度 | 0-3 |
| `sweet` | 嗜甜程度 | 0-3 |
| `thrifty` | 精打细算(省钱倾向) | 0-3 |
| `efficient` | 效率优先(讨厌纠结) | 0-3 |
| `ritual` | 仪式感(固守习惯与经典) | 0-3 |

## 二、三道题与计分规则

### Q1 -> `late_night`(凌晨一点的你, 更可能在干嘛?)

| 选项 | 文案 | late_night |
|---|---|---|
| A | 早睡了, 明天还要搬砖 | 0 |
| B | 再刷五分钟手机就睡 | 1 |
| C | 赶 due / 修 bug, 凌晨是常态 | 2 |
| D | 凌晨四点的麦门, 你懂 | 3 |

### Q2 -> `thrifty` / `efficient` / `ritual`(点餐决策风格)

| 选项 | 文案 | 计分 |
|---|---|---|
| A | 先翻券包, 没有满减绝不下单 | thrifty +3 |
| B | 30 秒点完常吃的那款, 拒绝纠结 | efficient +3 |
| C | 老配方老时间老位置, 仪式感拉满 | ritual +3 |
| D | 看心情, 随机刷新隐藏吃法 | +0 |

### Q3 -> `spicy` / `sweet` / `efficient` / `ritual`(本命口味组合)

| 选项 | 文案 | 计分 |
|---|---|---|
| A | 不辣不甜, 经典原味永流传 | +0 |
| B | 辣与甜我全都要, 双倍快乐 | spicy +2, sweet +2 |
| C | 无辣不欢, 辣度直接拉满 | spicy +3, sweet +3 |
| D | 一人食快速解决, 顺手走个固定流程 | efficient +2, ritual +1 |

## 三、人格判定矩阵

| 优先级 | 人格 | Emoji | 条件 |
|---:|---|---|---|
| 1 | 凌晨四点麦门人 | 🌙 | `late_night == 3` |
| 2 | 麦辣嗜辣者 | 🌶️ | `spicy >= 2` 且 `late_night >= 1` |
| 3 | 巨无霸原教旨派 | 🍔 | `ritual >= 2` 且 `efficient <= 1` 且 `spicy == 0` |
| 4 | 薯条原教旨主义者 | 🍟 | `ritual >= 2` 且 `spicy <= 1` |
| 5 | 券包仓鼠 | 🐹 | `thrifty >= 2` |
| 6 | 麦咖啡续命党 | 🥤 | `late_night >= 2` |
| 7 | 麦淇淋甜蜜派 | 🍦 | `sweet >= 2` |
| 8 | 麦当劳效率侠 | ⚡ | `efficient >= 2` 且 `ritual <= 1` |
| 兜底 | 随心配体验官 | 🎲 | 以上均未命中时使用（v2 起独立为正式人格） |

### 优先级设计说明

1. **条件越苛刻, 优先级越高。** "凌晨四点麦门人" 要求 `late_night` 精确等于 3,
   是最 specific 的规则, 必须最先判定, 否则会被 "麦咖啡续命党"(`late_night >= 2`)
   等宽条件覆盖。
2. **子集规则必须先判定。** "巨无霸原教旨派" 的条件是 "薯条原教旨主义者" 的
   严格子集(`ritual>=2 且 spicy<=1 且 efficient<=1` ⊂ `ritual>=2 且 spicy<=1`)。
   若先判定薯条, 巨无霸将永远无法命中, 因此巨无霸排在薯条之前。
3. **v2 新增人格排在后位。** "麦淇淋甜蜜派"(嗜甜) 与 "麦当劳效率侠"(高效率
   低仪式) 特异性低于经典人格, 排在其后, 保证经典人格的判定结果与 v1 一致。
4. **兜底人格保证完备性。** 例如 `{"q1":"A","q2":"D","q3":"A"}`(全零分)
   不命中任何规则, 此时返回兜底人格"随心配体验官", 保证任何合法答题组合
   都有结果。

## 四、MBTI 式四字母代码

从 6 个维度中取 4 个最具麦门特色的二分维度, 每个维度得分 **≥2 取高侧字母**,
否则取低侧字母, 拼成四字母代码(如 `LSGU`), 共 16 种组合, 每种组合有专属称号。

| 位置 | 维度 | 高侧(≥2) | 低侧(<2) | 高侧释义 | 低侧释义 |
|---:|---|---|---|---|---|
| 1 | `late_night` | L 凌晨型 | D 养生型 | 凌晨的麦门才是正统麦门 | 早睡早起, 早餐卡忠实用户 |
| 2 | `spicy` | S 嗜辣型 | B 原味型 | 无辣不欢, 辣度即态度 | 经典原味, 岁月静好 |
| 3 | `thrifty` | F 省钱型 | G 豪横型 | 券包比代码仓库还整洁 | 想吃就点, 预算不存在 |
| 4 | `ritual` | U 仪式型 | C 随性型 | 老配方老位置老时间 | 随机刷新, 惊喜常在 |

### 16 种组合称号表

| 代码 | 称号 | 代码 | 称号 |
|---|---|---|---|
| LSFU | 凌晨四点·辣味守夜人 | LBFU | 夜班经典守护者 |
| LSFC | 午夜辣妹·券王 | LBFC | 午夜性价比散人 |
| LSGU | 深夜食堂主理人 | LBGU | 深夜全餐鉴赏家 |
| LSGC | 凌晨放纵派掌门 | LBGC | 凌晨随机干饭王 |
| DSFU | 晨间辣味卷王 | DBFU | 晨间省典守味人 |
| DSFC | 晨间辣妹效率派 | DBFC | 清晨性价比散人 |
| DSGU | 晨间全餐仪式党 | DBGU | 晨间原味鉴赏家 |
| DSGC | 晨间豪横干饭人 | DBGC | 清晨随缘干饭人 |

> `sweet` 与 `efficient` 两个维度仍参与人格判定, 只是不进入四字母代码。
